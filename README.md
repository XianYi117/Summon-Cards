# 召喚 Summon Cards

雙人卡牌對戰網頁遊戲（版本 vj.1023.0）。

**立即遊玩：** https://xianyi117.github.io/Summon-Cards/

## 玩法

- **開始對戰（電腦）**：選擇自己和電腦的隊長、牌組後開打。
- **連線對戰（雙人）**：一人按「建立房間」取得房間代碼，另一人輸入代碼加入；雙方選好隊長牌組並按「準備完成」就會開始。
- 對戰畫面右側有牌型速查表，「規則」按鈕可以看規則速覽，「紀錄」可以看每一步和時間。

## 規則摘要

- 每人 20 張牌（一種屬性最多 7 張）＋ 1 位隊長，起手 5 張，先拿 4 分獲勝。
- 每回合：補牌 → 出牌（1～4 張）→ 翻牌 → 戰力計算 → 召喚石像 → 整理。
- 牌型：AAAA 7、AAAB 6、AAA 5、AABB 4、AAB／AABC 3、AA 2、沒成對 1。
- 剋制：火剋草、草剋水、水剋火，雙方牌型同等級時剋制方 +2。

## 檔案

| 檔案 | 內容 |
|---|---|
| `index.html` | 畫面與樣式 |
| `data.js` | 卡牌與隊長資料 |
| `engine.js` | 規則引擎與電腦 AI |
| `ui.js` | 畫面互動、連線對戰 |
| `cards/` | 卡圖（WebP） |

連線對戰使用 [PeerJS](https://peerjs.com/)（WebRTC 點對點），不需要自架伺服器；部分公司或學校網路可能無法連線。
